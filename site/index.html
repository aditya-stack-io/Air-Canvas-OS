Air-Canvas OS

Turn any standard webcam and microphone into a touchless spatial desktop. Sketch in mid-air, steer your OS cursor with smoothed hand tracking, scroll documents, and trigger commands hands-free with background voice recognition.

Three spatial modes

Canvas

Low-latency freehand air drawing, a hover-select top dock, pinch-to-resize brush (2–45px), 15-step undo/redo and one-click PNG export.

Cursor

Maps 21-point hand landmarks to screen coordinates with exponential smoothing and a dead-zone margin. Pinch to left-click or right-click.

Scroll

Touchless two-finger vertical scrolling with proportional speed control.

Voice HUD

SpeechRecognition and pyttsx3 run on non-blocking threads so camera FPS never drops. Falls back to HUD and keyboard controls when there's no microphone.

Quick start

Air-Canvas OS is a Python desktop app. It needs a local webcam and OS access, so it runs on your machine, not in the browser.

git clone https://github.com/aditya-stack-io/Air-Canvas-OS.git
cd Air-Canvas-OS
pip install -r requirements.txt
python air_canvas_os.py

Requires Python 3.9+, OpenCV 4.8+, MediaPipe, NumPy, PyAutoGUI, SpeechRecognition, pyttsx3 and PyAudio.
